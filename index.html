01
Snippet Searcher — Microservices Platform
Code

The largest project I've built. A two-part Systems Engineering capstone: first, a custom programming language (PrintScript) implemented from scratch in Kotlin — streaming Lexer, AST Parser, Interpreter, configurable Formatter and Static Code Analyzer (YAML/JSON rules), built on SOLID principles and GoF patterns. Second, a full microservices web platform on top of it — 8 independent services (snippet, execution, static analysis, user, gateway, UI, infra, asset) with Auth0 authentication, deployed on Azure with separate dev and prod VMs. CI/CD with Docker: updating a service rebuilds its container in place; updating infra rebuilds all services. Branch-based continuous delivery with Gradle.

My role: architecture design, Azure VM setup and management, full CI/CD pipeline configuration, cloud infrastructure lead — plus active contributions to service development across the platform.
