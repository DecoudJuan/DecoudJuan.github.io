04
Snippet Searcher — Microservices Platform

The largest and most complex project I've built. A two-part Systems Engineering capstone: first, a custom programming language (PrintScript) implemented from scratch in Kotlin — including a streaming Lexer, AST-based Parser, Interpreter, configurable Formatter and Static Code Analyzer (YAML/JSON rules), built following SOLID principles and GoF patterns. Second, a full microservices web platform on top of it — 8 independent services (snippet, execution, static analysis, user, gateway, UI, infra, asset) deployed on Azure with separate dev and prod VMs. CI/CD pipeline with Docker: updating a service pulls down its container, rebuilds it, and brings it back up; updating infra rebuilds all services. Branch-based continuous delivery with Gradle. Auth0 for authentication.

My role: architecture design, Azure VM setup and management, full CI/CD pipeline configuration, cloud infrastructure lead — plus active contributions to service development across the platform.

Kotlin TypeScript Docker Azure CI/CD Gradle Auth0 Microservices REST APIs
